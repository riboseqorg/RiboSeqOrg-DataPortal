Help & Information

Ribosome Decision Graphs (RDGs) visualize the potential translation pathways through an mRNA transcript.

  • Translons: Regions between a start codon and stop codon that could be translated
  • Reinitiation: When enabled, the ribosome can potentially restart translation after termination
  • Start Codons: Comma-separated list of codons that can initiate translation (e.g., ATG,CTG,GTG)

For more information, visit the RDG GitHub repository.
