About us

RiboSeq.Org is a platform for sharing and analysing ribosome profiling data. Our goal is to provide a user-friendly interface for exploring publicly available ribosome profiling datasets and facilitating data-driven discoveries in the field of translation regulation.

Sample fields

Fields shown on the Samples page:

Run
The unique run identifier for the dataset.
Study
The BioProject accession from which this run originated.
Organism
The species from which the data were generated.
Library type
The library type of this run, inferred from metadata.
Inhibitor
The inhibitor used to stall ribosomes in the Ribo-Seq protocol.
Cell line
The cell line used in the Ribo-Seq protocol.
Sex
The inferred sex of the sample.

Study fields

Fields shown on the Studies page:

Name
Study name for this BioProject, typically “{First author} et al. {Year}”.
BioProject
The unique BioProject identifier for the dataset.
Organism
The species from which the data were generated.
Samples
The number of unique samples in this study.
Released
Date the data were deposited.
SRA / ENA
Links to the study on the Sequence Read Archive and the European Nucleotide Archive.

Download files

The following files can be downloaded for each processed sample:

Reads
Collapsed reads in FASTA format. Unique reads from the raw file, with counts stored in the header as >seq{read_number}_x{read_count}.
Alignment
Reads aligned to the reference genome, in collapsed BAM format. Read names follow the same scheme.
Profiles
Ribosome footprint positions in BigWig format, one file per strand.
FastQC report
Quality report generated by FastQC.
fastp report
Trimming and quality report generated by fastp.
